## ✨ Features

- **⚡ Instant Auto-Print**: Automatically captures and prints customer orders without manual print popups.
- **🖨️ Universal Printer Support**: Works seamlessly with thermal POS receipt printers, label printers, and standard laser/inkjet printers.
- **📄 Supported Document Types**: PDF, Images (PNG, JPG, BMP), Microsoft Word (`.docx`), and Excel (`.xlsx`).
- **🛡️ Zero-Retention Privacy**: Print jobs are securely processed in transient local memory and deleted immediately after spooling.
- **🔔 Windows System Tray Integration**: Runs quietly in the background near the Windows clock and starts automatically on system boot.

## 💻 System Requirements

- **Operating System**: Windows 10 (64-bit) or Windows 11 (64-bit)
- **RAM**: Minimum 512 MB RAM
- **Disk Space**: 50 MB free space
- **Network**: Active internet connection to connect to QRPrint Cloud

## 🚀 Setup & Installation Guide

1. **Download & Install**:
   - Download the latest **`QRPrint_Agent_Setup.exe`** from the links above.
   - Run the setup wizard and follow the prompts to complete the installation.

2. **Connect to Your Shop**:
   - Open the QRPrint Desktop Agent.
   - Log into your [QRPrint Merchant Dashboard](https://qrprint.codecrazy.in).
   - Enter your **Shop ID** and **Agent Token** shown on your dashboard settings page.

3. **Start Printing**:
   - Click **Connect**. The agent will detect your installed printers and status will change to **Online**.
   - You can minimize the window to keep it running silently in your system tray.

## 🔒 Security & Privacy Notice

QRPrint Desktop Agent is designed with enterprise security standards:
- End-to-end HTTPS encrypted communication with your QRPrint cloud dashboard.
